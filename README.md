# -20-
На нынешней работе мне иногда приходится выполнять проверку расчета УНЦ выполненного согласно приказу МЭ, без какой либо подтверждающей документации, только на логику (так у нас это называется). Т.е. необходимо проверить соблюдаются ли правила добавления расценок, нет ли лишних, все ли заполнено. У нас есть правила сохраненные в ecxele.
Программа читает файл с правилами и на основании этих правил выдает замечания к ф20. ф20 всегда имете установленный формат.
